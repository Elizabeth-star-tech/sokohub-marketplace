# 🛍️ SokoHub – Multi-Vendor Marketplace

**Many Vendors. One Marketplace.**

SokoHub is a modern, responsive multi-vendor marketplace website designed to bring multiple independent sellers and customers together on one platform.

The platform aims to provide a convenient online shopping experience where customers can discover products from different vendors, explore product categories, browse promotional offers, and purchase items through a centralized marketplace.

🌐 **Live Demo:** [Visit SokoHub](https://elizabeth-star-tech.github.io/sokohub-marketplace/)

---

## 📌 Project Overview

SokoHub is an e-commerce marketplace concept inspired by real-world platforms where multiple vendors showcase and sell their products through one website.

The project focuses on creating an organized shopping environment with product discovery, vendor listings, shopping cart functionality, and a checkout interface.

It demonstrates practical frontend development concepts, including responsive web design, user interface development, dynamic content handling, and e-commerce application structure.

## 🎯 Project Objectives

- Develop a modern and responsive marketplace website.
- Provide a centralized platform for multiple vendors.
- Create an intuitive product browsing experience.
- Implement product search and filtering interfaces.
- Develop shopping cart and checkout functionality.
- Improve frontend development and UI/UX design skills.
- Apply JavaScript and state management concepts to an e-commerce application.

## 💻 Installation and Setup

To run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/Elizabeth-star-tech/sokohub-marketplace.git
```

### 2. Navigate to the project folder

```bash
cd sokohub-marketplace
```

### 3. Open the project

Open the folder using Visual Studio Code.

### 4. Run the website

Open the `index.html` file in your browser or use the Live Server extension in Visual Studio Code.
